## Use the map

Preserve framework mental models across revisions: app-owned entity state, explicit updates/invalidation, ephemeral element trees, focus-path dispatch, explicit task/subscription lifetimes, and foreground/background separation.

Verify exact imports, features, return types, callback arity, macro forms, and platform support against the target repository's locked revision. Start with its lockfile or Git dependency, search local wrappers, then open only the source row relevant to the task. Treat examples as callback-shape evidence, not architecture mandates; do not inherit Zed editor conventions from the upstream monorepo.

Use the target's public `gpui::*` exports in application code. Consult private modules to understand behavior, not to create unstable imports. This snapshot's façade is [`src/gpui.rs`](https://github.com/zed-industries/zed/blob/bc538def4545534201bbfcac4e95ac34ea6501b6/crates/gpui/src/gpui.rs#L87-L333); the resolved target façade is authoritative.

## Revision-sensitive caveats

| Check                 | Snapshot observation—verify target                                                                            |
| --------------------- | ------------------------------------------------------------------------------------------------------------- |
| Actions               | Use `actions!` or `#[derive(Action)]`; checked-in key-dispatch prose mentions nonexistent `#[gpui::action]`   |
| Old element API       | GPUI 1 blog examples differ; snapshot phases are `request_layout` → `prepaint` → `paint`                      |
| Docs snippets         | Snapshot key-dispatch JSON and some published combined test options are malformed; use target source/examples |
| Platform claims       | Older macOS/Linux-only copy conflicts with the snapshot; verify target backend support                        |
| Render derive         | `#[derive(Render)]` renders `Empty`; it does not synthesize UI                                                |
| Task lifetime         | Dropping `Task` cancels immediately                                                                           |
| Subscription lifetime | Dropping cancels; detach changes ownership behavior                                                           |
| Change channels       | `notify` invalidates/observes; `emit` sends a typed event                                                     |
| Entity leases         | Re-entering the same entity during its read/update can panic                                                  |
| Async failure         | Weak/window access is fallible; some `AsyncApp` methods still panic after app loss                            |
| `as_mut`              | Async and test contexts intentionally panic; use bounded `update`                                             |
| Window choice         | `App::with_window` selects a recent window, not an entity-intrinsic one                                       |
| Propagation           | Action handlers stop by default; input handlers propagate by default                                          |
| Identity              | Repeated callsites need stable IDs for state/accessibility                                                    |
| Assets                | `use_asset` schedules redraw; `get_asset` does not                                                            |
| Text                  | `shape_line` rejects newlines; use `shape_text` for multiline                                                 |
| Foreground priority   | Ignored at this pin                                                                                           |
| Platform methods      | Trait presence does not guarantee backend support; defaults may no-op/return `None`                           |

## Search recipes

Run from a GPUI/Zed checkout; adapt paths for a consumer repository:

```sh
# Resolve symbols and signatures.
rg -n 'pub (struct|enum|trait|type|fn) Symbol\b|pub use .*Symbol' crates/gpui crates/gpui_*
rg -n '\.(observe|subscribe|on_action|spawn|spawn_in)\(' crates --glob '*.rs'

# Audit reactive and lifetime behavior.
rg -n 'cx\.(notify|emit)\(' crates --glob '*.rs'
rg -n '\.(spawn|background_spawn|spawn_in)\(' crates --glob '*.rs'
rg -n '\.(detach|detach_and_log_err|await)\b|Subscription' crates --glob '*.rs'
rg -n '\.downgrade\(\)|WeakEntity<' crates --glob '*.rs'

# Audit rendering, identity, and dispatch.
rg -n 'impl (Render|RenderOnce|Element) for ' crates --glob '*.rs'
rg -n '\.(id|with_id)\(|text!\(|use_(keyed_)?state\(' crates --glob '*.rs'
rg -n 'focus_handle|track_focus|key_context|on_action|KeyBinding::new' crates --glob '*.rs'
rg -n '\.(role|label|on_a11y_action)\(|AccessibleAction' crates --glob '*.rs'

# Audit hot paths and portability.
rg -n 'uniform_list\(|\blist\(|ListState|measure_all|\.cached\(' crates --glob '*.rs'
rg -n 'gpui_(macos|linux|windows|web|apple|wgpu)|cfg\(target_(os|family)' crates --glob '*.rs' --glob 'Cargo.toml'

# Track upstream churn.
git log -S'pub fn api_name' -- crates/gpui
git log -G'api_name\(' -- crates/gpui crates/gpui_*
```

When source and prose disagree, trust the target's locked implementation, then preserve the framework invariant while adapting the target-resolved signature.
